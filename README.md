# Jリーグチケット価格モニター

J1クラブの試合ごとの席種価格・完売状況を毎日自動チェックし、`ticket_prices.csv` に履歴を蓄積します。

## 使い方

1. このフォルダをGitHubリポジトリにする(`git init` → push)
2. GitHub Actionsが有効なら、`.github/workflows/monitor.yml` により毎日 JST 9:00 に自動実行される
3. 手動で試したい場合は Actions タブから「Run workflow」、またはローカルで:
   ```
   pip install -r requirements.txt
   python monitor.py
   ```

## 監視対象の追加方法

`monitor.py` 内の `TARGET_MATCH_URLS` に、各試合の座席選択ページURL
(`https://www.jleague-ticket.jp/sales/perform/xxxxxxx/001` の形式)を追加してください。

## 既知の制約(要確認・要調整)

- **クラブの試合一覧ページ**(`/club/{コード}/`)は、ボット対策により通常のHTTPリクエストで
  ブロックされる/404になるケースを確認しています。そのため今回のスクリプトは
  「試合ごとのURLを手動 or 別ルートで集めてリストに入れる」前提にしています。
  一覧ページから自動収集したい場合は、Playwright等のヘッドレスブラウザでの
  アクセスが必要になる可能性が高いです(別途対応が必要)。
- **完売判定**は、実際に完売した試合ページのHTML構造を未確認のため暫定ロジックです。
  完売中の試合が見つかったら `monitor.py` の `SOLD_OUT_PATTERNS` を実際の表示文言に合わせて
  調整してください。
- サイトへの負荷配慮のため、リクエスト間に1.5秒のウェイトを入れています。
  試合数が多い場合は実行時間・負荷にも注意してください。
